# GM 运营后台 P2（管控核）实施计划

> **Status:** done  
> **Design:** [`2026-09-21-gm-ops-p2-design.md`](2026-09-21-gm-ops-p2-design.md)（**Status: approved**）

**硬性顺序：** 策划文档 `approved` 后方可创建本文件并写业务代码。任务从策划的协议/数据/验收派生，勿重复长篇策划正文。

**Goal:** 交付 GM 禁言/解禁、限时封号、封号吊销 uid token、强制维护（拒登 + 全网关踢人），含控制台与单测。

**Architecture:** HTTP 会话鉴权 → NATS → ActorGM（account/world）与 gateway `ops.kickAll`；封禁/禁言写 accounts；维护 Redis；签发维护 uid→token 索引。

**Tech Stack:** Go / Cherry Actor / Protobuf / GORM / Redis / Vue 3 Naive UI
