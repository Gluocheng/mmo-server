# 怪物生成 策划文档

> **Status:** approved  
> **实施计划：** [`2026-10-08-combat-monster.md`](2026-10-08-combat-monster.md)

**For agentic workers:** 本期做可复用的怪物模板和刷怪点。玩法只配怪物 id。种子在荒野刷一只会追击、出手、死后回出生点复活的怪。不改 `Cast` / `ApplyBuff` 签名，不做客户端。

---

## 背景与目标

技能、药水和禁手已经能在玩家之间结算，地图上也分出了可战斗的荒野，但场上还没有怪物。怪物如果把生命和坐标写死在玩法里，换一张图就要改一次代码。

**一期目标：** 怪物是模板，刷在哪张图、哪条线、刷几只，由刷怪点决定。实例带上生成时拷贝的生命、攻击和防御，会追最近的玩家，走到攻击距离后出手，死亡后按刷怪点的时间在出生点复活。

---

## 用户场景

1. 玩家从主城切到荒野（地图 3，1 线），出生在 `(10,0,10)`。野狼站在 `(18,0,10)`，距离 8，比仇恨距离 6 更远，站在出生点不会被追。往前走进 6 格以内，狼沿直线追来。
2. 狼走进攻击距离 2 后停下，每 1.2 秒打出 6 点伤害。玩家普攻 10 点，扣掉狼的防御 2，实际掉 8。狼有 80 点生命，大约 10 下普攻能打死。玩家生命 100，站着对打会先打死狼。
3. 狼死亡后停在倒下的位置，Buff 清空，打不中。8 秒后在 `(18,0,10)` 满血站起来，不在倒下的地方复活。站起来的这一拍不追也不打。玩家自己仍是 5 秒原地复活。
4. 把狼拉到离它出生点超过 12 格，或者仇恨距离里没有活着的玩家，它停止出手并走回出生点。回到出生点不回血。
5. 狼身上有未到期的禁手时，这一拍不追也不打，攻击间隔继续走。禁手结束且间隔已经到了，当拍可以打。玩家被禁手时仍可以移动，只是不能出手和喝药。

## 功能范围

### 包含

- Luban 表 `monster`、`spawn`，导入 MySQL 后由现有 `runtime.Load` 读入
- 启动和配表热更时，按刷怪点生成、保留或移除实例
- 实例 uid 使用游戏节点已经初始化的雪花 `NextID()`，记下模板 id 和刷怪点 id
- 怪物占房间坐标，出现在附近列表、`onScenePresence` 和 `onMove` 里，不计入分线人数
- `SceneActor`、`ScenePresence` 增加单位类型和配置 id
- 与玩家同一个战斗心跳：防御减伤、追击、攻击距离内出手、禁手时停手、死亡后回出生点复活
- 种子：荒野 1 线一只野狼

### 不包含

- 寻路、巡逻、碰撞、怪物技能、怪物打怪物
- 掉落、经验、阵营、仇恨列表、被打强制拉怪
- 玩家防御、生命落库、客户端
- 修改 `Cast` / `ApplyBuff` 的参数
- 演武场木桩。攻击填 0 的模板本期不配

## 协议设计

不新增路由。点名打怪物仍走 `game.combat.cast`，目标填怪物 uid。

| 类型 | Route / 事件 | 请求 | 响应 / Push | 说明 |
|------|----------------|------|-------------|------|
| Push | `onScenePresence` | — | `ScenePresence` | 怪物生成或被移除时，推给同线 AOI 内的玩家 |
| Push | `onMove` | — | `MoveBroadcast` | 狼追击、回家、复活落到出生点时推给同线 AOI 内的玩家 |
| Push | `onCombatFrame` | — | `CombatFrame` | 打狼和狼出手都进现有命中。狼出手的 `skill_id=0` |

`SceneActor` 与 `ScenePresence` 各增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| `actor_type` | int32 | `0` 玩家，`1` 怪物。玩家不填时按 0。JSON 名 `actorType` |
| `config_id` | int32 | 怪物模板 id。玩家为 0。JSON 名 `configId` |

进场和切图响应里的 `nearby` 使用同一个 `SceneActor`。进场响应的 `players`、地图列表和 GM 在线名单只含玩家。怪物只出现在 `nearby`。怪物没有网关连接，不接收 `onMove`、`onScenePresence` 和 `onCombatFrame`。

怪物和玩家共用 AOI 半径 15。走过边界不另发出现和消失。只有坐标变了才推 `onMove`。

已有业务码继续使用：目标不在同图同线是 `40042`，超出技能距离是 `40043`，目标已死亡是 `40046`。本期不新增错误码。

**前置条件：** 玩家已进场。怪物在进程启动时就在对应线上，不依赖第一个玩家进图。

## 数据与持久化

| 表 / 缓存 | 字段 / Key | 索引 / TTL | 说明 |
|-----------|------------|------------|------|
| `cfg_monster` | id、name、hp、attack、defense、move_speed、attack_range、attack_interval_ms、aggro_range、leash_range | 主键 id | 模板。`move_speed` 是每秒位移，距离用 XZ |
| `cfg_spawn` | id、feature、scene_id、line、monster_id、x、y、z、count、respawn_ms | 主键 id | 一条点生成 `count` 只，每只单独出生点 |
| 进程内存 | 雪花 uid、模板 id、刷怪点 id、槽位、属性拷贝、当前目标、上次出手时间 | 删点或离场即删 | 不写 `accounts` / `players`。复活不重新发号 |

**事务：** 配表导入沿用现有 import 单事务。怪物运行状态不落库。

**热更：** 沿用 `game.config.reload`。

- `feature` 必须非空，只用来辨认这一行属于哪个玩法，不改变刷怪和战斗行为。
- 新的刷怪点，或同一点多出来的槽位：在该槽出生点满血生成。
- 已在场的槽位，怪物 id、地图、线、出生点、复活毫秒都没变：保留当前生命、死亡计时、Buff、目标和位置。模板数值改了也不刷新这只。
- 某个槽的怪物 id、地图、线、出生点或复活毫秒变了：只拆掉该槽，按新行满血生成。
- 数量变少时保留低槽位。从 4 改为 2 时保留槽位 0 和 1，拆掉 2 和 3。
- 点从配表消失，或这一行变得不合法、地图禁战、地图消失：移除它刷出的实例。

属性在生成时拷贝。死亡复活用的是这只实例自己的最大生命和复活毫秒，不是热更后的新表。

**种子：**

| 表 | 值 |
|----|----|
| monster id=1 | 名称「野狼」，生命 80，攻击 6，防御 2，移速 4，攻击距离 2，攻击间隔 1200 毫秒，仇恨距离 6，回家距离 12 |
| spawn id=1 | `feature=wild`，地图 3，1 线，怪物 1，坐标 `(18,0,10)`，数量 1，复活 8000 毫秒 |

荒野玩家出生点是 `(10,0,10)`，与狼相距 8。普攻扣防后是 8，10 下打死；狼每 1.2 秒打 6 点，玩家站桩对打会赢。

合法行才生成，非法行跳过，不挡住启动：

- 生命、攻击、攻击距离、攻击间隔、仇恨距离、回家距离、复活毫秒都至少为对应下限：生命 ≥ 1，攻击 ≥ 1，攻击距离 > 0，攻击间隔 ≥ 100，复活 ≥ 1000
- 防御 ≥ 0，移速 ≥ 0
- 回家距离 > 仇恨距离，仇恨距离 ≥ 攻击距离
- `feature` 非空，数量 1–4，怪物 id 能找到
- 地图存在、允许战斗，线号落在该图 `1..max_lines`

数量大于 1 时，第 i 只（从 0 计）的出生点是 `(x + i*2, y, z)`。

## 业务规则

- 同一只模板可以被很多刷怪点、很多槽位使用。实例 uid 调用游戏节点的 `cherrySnowflake.NextID()`，不使用怪物模板 id，也不使用 `id_sequences` 里的角色短号。game 启动时已用节点号 `SetDefaultNode`（默认 `10001`），与 login 账号雪花的节点槽不是同一个。新实例才发号；同一槽位死亡和复活保持这个 uid。进程重启后旧 uid 作废。
- 怪物用生成时拷贝的生命进战斗，最大生命来自模板。不调用玩家的 `combat.Enter`，也不走 `ArriveMain`。先把坐标放进房间，再写入战斗单位。持有世界锁时不调用战斗；心跳里要改坐标时，先算出位移，释放战斗锁后再写房间。只有坐标变了才推 `onMove`。
- 同一拍的顺序是：玩家技能、Buff 跳伤、玩家复活、怪物复活、仍然活着的怪物再决策。这一拍死掉的怪物不再出手。这一拍刚复活的怪物只回到出生点，下一拍才追击和出手。
- 距离只看 X 和 Z，与现有技能和 AOI 相同，比较用小于等于。正好等于仇恨距离算进入，正好等于攻击距离可以出手，正好等于回家距离还继续打。离出生点大于回家距离才回家。Y 保持出生点的 Y。
- 玩家打玩家仍是技能伤害原值。范围技能打圆心里除自己以外的活单位，包括怪物。
- 打到怪物时，技能伤害大于 0 则减去该怪物防御，至少为 1。技能伤害为 0 时造成 0 点，命中仍可挂 Buff。防御为 0 时等于原伤害。持续伤害和治疗不看防御。防御只减技能伤害和怪物这一下出手。
- 怪物出手用攻击减去目标防御，至少为 1。玩家本期没有防御，所以吃到的就是攻击力。这一下直接记进当前拍的命中，`skill_id=0`，不走 `Cast`，不进技能冷却。进入攻击距离的当拍可以打出第一下，之后按攻击间隔。
- 每个活着的怪物在战斗心跳里自行决定，不维护仇恨列表。多只怪物可以追同一个玩家。移速为 0 时不位移，玩家走进攻击距离后才出手：
  1. 自己离出生点的距离大于回家距离：清除目标，朝出生点走，不出手。
  2. 否则在仇恨距离内选最近的存活玩家。同一地图、同一条线，距离相同则 uid 更小的优先。
  3. 没有可选玩家：朝出生点走，不出手。
  4. 与目标距离大于攻击距离：沿直线走向目标，不出手。步长 = 移速 × 心跳毫秒 / 1000。
  5. 已经进入攻击距离：停步，并按攻击间隔出手。
- 剩余步长足够走到出生点时，坐标直接落到出生点，避免在家里来回抖。回家不回复生命，身上的 Buff 还在。
- 身上有未到期的禁手：不移动，不出手，攻击间隔继续走。禁手结束且间隔已经到了，当拍可以打。这只改变怪物自己的心跳，不改变玩家的禁手规则。
- 死亡清除 Buff 和目标，尸体留在倒下的坐标，附近列表仍能看到。复活计时从死亡那一拍开始，到点后在自己的出生点满血，Buff 不补回。玩家被怪物打死时走现有死亡：清掉 Buff，按战斗常量原地满血。
- 玩家复活仍读 `cfg_combat_const.respawn_ms`，原地站起。怪物不走这条时间。
- `countLine`、地图列表和 GM 在线名单只数玩家。怪物在场不改变 50 人上限。
- 主城不允许战斗，配到主城的刷怪点跳过。热更后这一行不合法、地图禁战或地图消失，按删点拆掉实例。

## 验收标准

- [x] 配表可导入，启动 `Load` 能读到野狼和荒野刷怪点
- [x] 荒野生成 1 只狼，附近列表带有类型和模板 id，分线人数不增加
- [x] 普攻 10 点打在防御 2 上掉 8；伤害 0 的技能仍然是 0
- [x] 玩家走进仇恨距离后，狼沿直线靠近，进入攻击距离后按 1200 毫秒掉血
- [x] 玩家离开仇恨距离，或狼离出生点超过 12，狼停止出手并回到 `(18,0,10)`
- [x] 狼被禁手期间不移动也不出手；玩家被禁手时移动仍成功
- [x] 狼死亡后打不中，8 秒后在出生点满血，uid 不变；玩家复活仍是 5 秒原地
- [x] 删掉刷怪点或热更改了坐标后，旧实例被移除
- [x] 进场响应的 `players` 不含怪物 uid，怪物只在 `nearby`
- [x] `go test ./...` 通过

## 风险与依赖

| 项 | 说明 |
|----|------|
| 依赖 | 战斗心跳、场景坐标与 AOI、配表 import / Load、地图 3 允许战斗 |
| 迁移 | 新表由 AutoMigrate 创建。须重新导表后荒野才有狼 |
| 兼容 | `SceneActor` 与 `ScenePresence` 只追加字段。旧客户端不读类型时仍能看到坐标。无新路由 |
| 锁顺序 | 世界锁和战斗锁不能反向嵌套。生成时先坐标、后战斗；心跳移动时先放开战斗锁再写坐标 |
| 观众 | 现有合包会遍历全部战斗单位。怪物没有网关，不能给它们发帧 |
