# 配置库与玩家库分开 实施计划

> **Status:** done  
> **Design:** [`2026-11-12-split-db-design.md`](2026-11-12-split-db-design.md)（**Status: approved**）

**Goal:** 玩家数据留在 `mmo`，配置表改到同一台 MySQL 的 `mmo_cfg`。

**Architecture:** `mysql.dsn` 只服务玩家库。`mysql.config_dsn` 在游戏加载、热更、GM 目录和导入时打开。登录节点不打开配置库。单测的两个句柄指向同一个 sqlite。

**Tech Stack:** Go / GORM / MySQL
