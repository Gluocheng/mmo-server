# 躲闪 策划文档

> **Status:** approved  
> **实施计划：** （策划通过后创建）[`2026-11-11-dodge.md`](2026-11-11-dodge.md)

**For agentic workers:** 本期只让躲闪进入结算。躲闪率用整数万分比，不用 `double`。出手前按目标躲闪率掷点，掷中则这次不掉血、不暴击、不吸血。持续伤害不躲。不改 `Cast` / `ApplyBuff` 签名，不新增路由。`Status: approved` 前不得创建实施计划、不得改业务代码。

---

## 背景与目标

技能出手、暴击、穿透、伤害加成、受伤减免、吸血和持续伤害都已经会掉血。目标身上没有「这次没打中」的判定。[`gameconfig/datas/stat.csv`](../../gameconfig/datas/stat.csv) 里有 `dodge`，但是 `settle=false`，装备表写上它会被导入拒绝。

**一期目标：** 躲闪率以整数万分比结算。`10000` 表示 `100%`，`2000` 表示 `20.00%`，`1` 表示 `0.01%`。普攻、范围技能和怪物出手在算伤害之前用整数掷点。没穿躲闪装备、也没挂躲闪 Buff 时，掉血与现在相同。

---

## 用户场景

1. 玩家穿着软布鞋，躲闪率 `2000`（`20.00%`）。对方普攻掷中躲闪时，这一下伤害为 0，不标暴击，也不出现吸血治疗。生命与出手前相同。
2. 躲闪率 `0` 时，普攻对防御 0 仍掉 10，对野狼仍掉 8。
3. 躲闪率 `10000` 时，普攻和范围斩的伤害都是 0。范围斩附带的撕裂仍然挂上，下一跳照常掉血，这一跳不再掷躲闪。

## 功能范围

### 包含

- `dodge` 改为 `settle=true`。`allow_flat` 仍为 false，`allow_percent` 仍为 true
- 装备属性和 `attr` Buff 可以写躲闪。数值列保持整数，不改成小数。表里的数就是万分比
- 最终躲闪率是 `int32`，基础 0，点数相加后限制在 0 到 `10000`
- 强化对躲闪这条仍追加 `max(1, 原数值 × 等级 / 10)`。软布鞋 `2000` 强化到 1 级追加 `200`，最终 `2200`（`22.00%`）
- 技能出手和怪物出手在算伤害前掷点。掷中则伤害 0、不暴击、不吸血
- 命中增加布尔字段表示是否躲开。快照和属性变化带上万分比最终值
- 种子：软布鞋，鞋子部位，躲闪率 `2000`

### 不包含

- 招架、格挡、急速、冷却缩短、移动速度
- 法力、主属性、精通、元素伤害
- 用攻击方命中去抵消躲闪。`hit` 仍不结算
- 持续伤害和持续治疗掷躲闪
- 新战斗路由、客户端表现
- 修改 `Cast` / `ApplyBuff` 的参数
- 躲开后取消技能附带的 Buff
- 把 `cfg_equip_attr.value`、`cfg_buff.value` 或协议里的躲闪率改成 `double`

## 协议设计

不新增 RPC。

| 类型 | Route / 事件 | 请求 | 响应 / Push | 说明 |
|------|----------------|------|-------------|------|
| Push | `onCombatFrame` | — | 现有帧 | 命中增加布尔字段 `dodge`；`stats` 和 `self` 增加 `int32` 字段 `dodge_rate` |
| Push | `onCombatSnapshot` | — | 现有快照 | 增加 `int32` 字段 `dodge_rate` |

`dodge=true` 表示这一下被躲开，`amount` 为 0，`crit` 为 false。`dodge_rate` 是万分比，没有加成时为 `0`。面板上的百分比由客户端除以 `100` 显示，服务器不存小数。

**业务错误码草案：** 不新增。

**前置条件：** 已进场。属性仍在战斗心跳里算。

## 数据与持久化

| 表 / 缓存 | 字段 / Key | 索引 / TTL | 说明 |
|-----------|------------|------------|------|
| `cfg_stat` | `dodge` 行 `settle=true` | 主键 id | 允许百分比，不允许固定值。数值单位是万分比 |
| `cfg_item` | id=2005 | 主键 id | 软布鞋，装备，不可堆叠，背包类型 4，部位组 8（鞋子） |
| `cfg_equip_attr` | 新行，`value` 仍是 `int` | 主键 id | 2005，`dodge`，`percent`，`2000` |
| `cfg_buff` | `value` 仍是 `int` | 主键 id | `attr` 且 `stat=dodge` 时填写万分比，例如 `1` 或 `10000` |
| 进程内存 | 单位躲闪率最终值，`int32` | 离场即删 | 不写 `players` |

**事务：** 配表导入沿用现有 import 单事务。战斗结算不落库。

**热更：** 沿用 `game.config.reload`。新穿上的装备和新挂的 Buff 读新表。已经挂上的 Buff 仍用施加时的拷贝。穿着中的装备按新表重算。

**种子：** 玩家基础躲闪率是 `0`。不穿软布鞋、不挂躲闪 Buff 时不会躲闪。测试边界用 `1`（`0.01%`）和 `10000`（`100%`），不靠小数。

## 业务规则

- 躲闪率是万分比整数：基础 `0`，全部点数相加，限制在 `0` 到 `10000`。配表不允许固定值，所以装备只能写百分比。这里的百分比点数就是万分比本身，不再除以 `100`。
- 点名、范围技能和怪物出手在通过距离、存活这些现有检查之后、先重算双方属性，再判断这次出手值。出手值是现有公式的第 1 步（技能伤害 + 攻击 × 系数 / 100），还没掷暴击、还没减防御。
- 出手值小于等于 0 时不掷躲闪，命中 `dodge=false`。禁手就是这种技能。
- 出手值大于 0 时，按**目标**躲闪率做整数掷点：在 `0` 到 `9999` 里取一个数，小于躲闪率则躲开。范围技能里每个目标单独掷。躲闪和暴击各用一条可注入的掷点。躲开时不再掷暴击。
- 掷中：这次命中 `amount=0`、`crit=false`、`dodge=true`，目标生命不变，不写吸血治疗，不记伤害榜，不刷新最后一击，冷却不退。技能附带的 Buff 仍按现在的规则挂上。
- 没掷中：`dodge=false`，再进入现在的暴击、穿透、加减伤和吸血。
- 躲闪率小于等于 `0` 时不掷，一定不躲。大于等于 `10000` 时一定躲。
- 本期不看攻击方命中。`hit` 仍不结算。怪物躲闪率基础是 `0`，怪物表不加这一列。
- 持续伤害走现有跳伤结算，不掷躲闪。持续治疗不掷躲闪。
- 快照和 `stats` 在躲闪率相对上一拍有变化时带上最终万分比。没有变化时不为它单独发包。

## 验收标准

- [x] 躲闪率 `0` 时，普攻对防御 0 仍掉 10，对野狼仍掉 8，命中 `dodge=false`
- [x] 躲闪率 `10000` 时，普攻伤害为 0，不暴击，不吸血，生命不变，命中 `dodge=true`，且没有暴击掷点
- [x] 禁手这种出手值为 0 的技能不标 `dodge=true`
- [x] 躲闪率 `10000` 时，范围斩伤害为 0，撕裂仍然挂上，下一跳持续伤害仍掉血且 `dodge=false`
- [x] 软布鞋能穿上，躲闪率最终值是 `2000`。强化到 1 级后是 `2200`
- [x] 装备或 Buff 配躲闪 `1` 可以导入。攻击仍是整数，数值列不改成小数
- [x] `go test` 战斗、装备和导表通过

## 风险与依赖

| 项 | 说明 |
|----|------|
| 依赖 | 现有出手顺序、装备穿着、强化追加、战斗同步的快照和 `stats` |
| 迁移 | 只改 `cfg_stat.settle` 并追加鞋子种子。旧角色躲闪率是 `0` |
| 兼容 | 命中和快照只追加字段。`dodge_rate` 是万分比整数。旧客户端忽略 `dodge` 时，躲开的那一下会看到伤害 0 |
| 随机 | 躲闪由服务端做 `0` 到 `9999` 的整数掷点。测试要能注入躲开或没躲开，且不消耗暴击掷点 |
| 显示 | 客户端把 `dodge_rate / 100` 显示成百分数，保留两位小数。服务器不发 `double` |
