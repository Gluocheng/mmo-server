# 装备属性扩充 策划文档

> **Status:** approved  
> **实施计划：** [`2026-11-03-equip-stats.md`](2026-11-03-equip-stats.md)

**For agentic workers:** 本期把暴击率、暴击伤害、穿透、伤害加成、受伤减免、吸血改成结算。装备和 `attr` Buff 都能加。生命、攻击、防御的算法不变。不改 `Cast` / `ApplyBuff` 签名，不做客户端。

---

## 背景与目标

装备和属性 Buff 现在只能改生命、攻击、防御。[`gameconfig/datas/stat.csv`](../../gameconfig/datas/stat.csv) 里虽然有暴击、穿透这些名字，但 `settle=false`，装备表不能配，出手也不看它们。

**一期目标：** 这六项进入同一套固定值加百分比的公式，并在减防前后按固定顺序生效。没穿对应装备、也没挂对应 Buff 时，掉血与现在相同。

---

## 用户场景

1. 玩家穿着新手木剑，暴击率 10。这一下掷中暴击时，出手值先按 150% 计算，再减防御。没掷中时，掉血与现在相同。
2. 玩家穿着布衣，受伤减免 5。对方打出的伤害在减防之后再乘 95%。结果小于 1 且原来出手值大于 0 时，仍掉 1。
3. 玩家穿着铜戒，吸血 5。造成 20 点伤害时回复 1 点，不超过自己已损失的生命。这口回复出现在同一拍的命中里。持续伤害按同样的比例吸血。

---

## 功能范围

### 包含

- `crit_rate`、`crit_damage`、`penetrate`、`damage_bonus`、`damage_reduction`、`lifesteal` 改为 `settle=true`
- 装备属性和 `attr` Buff 可以写这六项。强化对这六条仍追加 `max(1, 原数值 × 等级 / 10)`
- 出手在现有攻击和减防之间插入暴击、穿透，减防之后再乘伤害加成和受伤减免
- 吸血按最终伤害回复攻击方，写成同一拍的治疗
- 快照和属性变化带上这六项的最终值。命中增加是否暴击
- 种子：木剑暴击率 10，布衣受伤减免 5，铜戒吸血 5，新戒指暴击伤害 20

### 不包含

- 躲闪、招架、格挡、急速、冷却缩短、移动速度
- 法力、主属性、精通、元素伤害
- 新战斗路由、客户端表现
- 修改 `Cast` / `ApplyBuff` 的参数

## 协议设计

不新增 RPC。

| 类型 | Route / 事件 | 请求 | 响应 / Push | 说明 |
|------|----------------|------|-------------|------|
| Push | `onCombatSnapshot` | — | 现有快照 | 增加六项最终值 |
| Push | `onCombatFrame` | — | 现有帧 | `stats` 增加六项；命中增加 `crit` |

六项都是最终百分比整数。没有加成时为 0。`crit=true` 表示这一下已经按暴击乘数算过。吸血治疗的 `heal=true`，来源是攻击方，目标也是攻击方。

**业务错误码草案：** 不新增。未结算属性仍不能配进装备表，导入失败。

**前置条件：** 已进场。属性仍在战斗心跳里算。

## 数据与持久化

| 表 / 缓存 | 字段 / Key | 索引 / TTL | 说明 |
|-----------|------------|------------|------|
| `cfg_stat` | 上述六行 `settle=true` | 主键 id | `allow_flat` / `allow_percent` 不改。暴击率、暴击伤害、穿透、伤害加成、受伤减免只有百分比；吸血两者都允许 |
| `cfg_equip_attr` | 现有行 | 主键 id | 追加种子行 |
| `cfg_item` | id=2004 | 主键 id | 锋锐戒 |
| 进程内存 | 单位这六项的最终值 | 离场即删 | 不写 `players` |

**事务：** 配表导入沿用现有 import 单事务。战斗结算不落库。

**热更：** 沿用 `game.config.reload`。新挂的 Buff 和新穿上的装备读新表。已经挂上的 Buff 仍用施加时的拷贝。穿着中的装备按新表重算。

**种子：**

| 对象 | 值 |
|------|----|
| 2001 新手木剑 | 原有攻击固定 +5，再加暴击率 10 |
| 2002 布衣 | 原有生命 +20、防御 +3，再加受伤减免 5 |
| 2003 铜戒 | 原有攻击固定 +1，再加吸血 5 |
| 2004 锋锐戒 | 装备，不可堆叠，背包类型 4，部位组 10。暴击伤害 20 |

玩家基础六项都是 0。不穿这些装备、不挂对应 Buff 时，不会暴击，穿透和加减伤都是 0。

## 业务规则

- 六项的最终值仍是 `(基础 + 全部固定加成) × (100 + 全部百分比) / 100`，向下取整。基础为 0。固定加成和百分比都包含 Buff 与当前穿着。
- 暴击率限制在 0 到 100。暴击伤害最低为 0。穿透限制在 0 到 100。伤害加成最低为 0。受伤减免限制在 0 到 75。吸血限制在 0 到 100。
- 出手顺序：
  1. 出手值 = 技能伤害 + 最终攻击 × 系数 / 100。小于 0 时当作 0。
  2. 服务端按暴击率掷点。掷中时，出手值再乘 `(150 + 暴击伤害) / 100`，向下取整，并把这一下标成暴击。
  3. 有效防御 = 防御 × (100 - 穿透) / 100，向下取整。出手值大于 0 时减去有效防御，至少为 1。出手值为 0 时造成 0。
  4. 再乘 `(100 + 伤害加成) / 100`，然后乘 `(100 - 受伤减免) / 100`，都向下取整。结果小于 1 且第 1 步的出手值大于 0 时，仍为 1。
- 吸血量 = 最终造成的伤害 × 吸血 / 100，向下取整。回复攻击方，不超过他已损失的生命。回复为 0 时不写治疗命中。
- 持续伤害的基数是配表数值乘层数，不加攻击系数。之后与普攻相同：暴击、穿透后减防御、伤害加成、受伤减免，并按最终跳伤吸血。来源已离场时暴击、穿透、加成和吸血按 0。
- 持续治疗只被来源的暴击和伤害加成放大。穿透、受伤减免和吸血不改变治疗数字。
- 怪物出手走同一条顺序。怪物的六项基础值是 0，只能靠以后的模板扩展；本期怪物表不加这些列。
- 快照和 `stats` 在这六项相对上一拍有变化时带上最终值。没有变化时不为它们单独发包。

## 验收标准

- [x] 暴击率 0 时普攻对防御 0 仍掉 10，对野狼仍掉 8
- [x] 暴击率 100、暴击伤害 0 时，出手值按 150% 计算后再减防御，命中 `crit=true`
- [x] 穿透 100 时，对方防御不减伤
- [x] 伤害加成 100 使减防后的伤害翻倍；受伤减免 75 再留下四分之一，且不会变成 0
- [x] 吸血 50 在造成 10 点伤害时回复 5，不超过已损失生命
- [x] 持续伤害按普攻后半段结算并吸血；持续治疗只被暴击和伤害加成放大
- [x] 木剑、布衣、铜戒、锋锐戒的种子属性能穿上并进入最终值
- [x] 未结算属性仍不能导入到装备表
- [x] `go test ./...` 通过
