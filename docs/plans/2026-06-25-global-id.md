# 全局 ID 生成策略实施计划

> **Status:** done
> **Design:** [`2026-06-25-global-id-design.md`](2026-06-25-global-id-design.md)（须 **Status: approved**）
> **For agentic workers:** 按任务勾选推进；完成后更新 `docs/plans/README.md` 总览表。

**Goal:** 将账号 UID 改为 Snowflake 全局 ID，将角色 `player_id` 改为不含服务器语义的全局短数字 sequence。

**Architecture:** 账号创建在 persistence 层主动生成 Snowflake UID，不再依赖 MySQL 自增。角色创建在同一事务内从 `id_sequences` 表分配短数字 ID，再写入 `players`，确保角色插入失败时 sequence 同步回滚。

**Tech Stack:** Go / Cherry Snowflake / GORM / Redis / SQLite 单测
