**Goal:** 为 GM HTTP 补齐鉴权、查账号/角色/背包、按 player_id 发奖、踢下线与审计，验收走 curl。

**Architecture:** HTTP 共享 token → NATS ClusterPacket → `ActorGM` 子域（account/player/bag/config）；发奖走 persistence，不经过玩家 Session。

**Tech Stack:** Go / Cherry Actor / Protobuf / GORM / Redis
