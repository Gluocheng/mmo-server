**Goal:** 躲闪率以万分比整数结算。出手值大于 0 时先掷点，躲开则不掉血、不暴击、不吸血。

**Architecture:** 躲闪率与暴击分开掷点。`resolveStrike` 先算出手值，大于 0 再按目标躲闪率在 0 到 9999 里掷点。没躲开才进入现有暴击和减伤。持续伤害不走这条判定。

**Tech Stack:** Go / Cherry Actor / Protobuf / GORM / Redis
